# Text Cleaner

**Typography, refined.**

Text Cleaner is a typography checker for Figma Design. Find issues in selected objects or the current page, locate them on the canvas, and apply available corrections without leaving Figma.

Current development version: **1.1.0**. Figma Community publication is pending.

## Features

- Seven typography checks: multiple spaces, spaces before punctuation, straight quotes, possible dash issues, measurement units, numeric ranges and missing spaces.
- Live checking after the first manual scan.
- Individual and eligible batch corrections, with formatting preservation safeguards.
- English and Russian interface.
- No external processing services or separate account.

Typography rules primarily target Russian text, with partial English support. Review ambiguous findings manually.

## О плагине

Text Cleaner — инструмент типографической проверки прямо в Figma. Проверяйте выделенные объекты или страницу, находите проблемные символы и применяйте доступные исправления. Автопроверка активируется после первого ручного поиска.

Интерфейс доступен на русском и английском. Правила преимущественно ориентированы на русскую типографику. Текст обрабатывается внутри среды плагина без передачи на сторонние серверы.

Этот репозиторий предназначен для документации и поддержки, а не для распространения исходного кода.
