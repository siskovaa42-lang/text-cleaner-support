# Text Cleaner — Privacy Policy / Политика конфиденциальности

Effective date / Дата вступления в силу: 2026-11-26

## English

This policy describes Text Cleaner 1.1.0, a Figma Design plugin maintained by the GitHub account [siskovaa42-lang](https://github.com/siskovaa42-lang).

### Data processed
When you start a scan, the plugin reads text layers in the selected objects or current page, subject to your scan settings. It processes text, layer identifiers, relevant formatting and document structure to identify issues, locate them on the canvas and apply corrections you explicitly request.

### Storage and transmission
Text and scan results are processed within the Figma plugin environment during the session. The plugin does not send them to the developer or external servers, and does not persist document text, results or ignored issues. Its manifest disallows external network access. It does not use analytics, advertising trackers or third-party processing services.

The plugin stores preferences through Figma clientStorage: interface language, selected rules, scan scope, visibility filter and collapsed issue categories. These preferences persist between sessions. No separate plugin account is required.

### Sharing and retention
The developer does not receive document contents through the plugin. Edits requested by you become part of your Figma document and are subject to Figma's own storage and sharing settings. Session data is no longer retained by the plugin after its session ends; saved preferences may remain in Figma's plugin storage.

Figma and GitHub independently process data under their own policies: [Figma Privacy Policy](https://www.figma.com/legal/privacy/) and [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### Support and your choices
If you voluntarily submit a GitHub issue, its contents and your public GitHub profile may be visible to others. Do not include confidential documents, personal data or customer text. Use anonymized examples. You can stop plugin processing by closing the plugin and control its scope through its settings.

For questions about privacy or requests concerning data you voluntarily provide, contact the maintainer via [GitHub Issues](https://github.com/siskovaa42-lang/text-cleaner-support/issues). Please do not post sensitive details publicly.

This policy may be updated as the plugin changes. The latest version will be available on this page.

## Русский

Политика описывает работу Text Cleaner 1.1.0 — плагина Figma Design, сопровождаемого владельцем аккаунта GitHub [siskovaa42-lang](https://github.com/siskovaa42-lang).

### Какие данные обрабатываются
После запуска проверки плагин читает текстовые слои выделенных объектов или текущей страницы согласно настройкам. Текст, идентификаторы слоёв, необходимые сведения о форматировании и структуре документа используются для поиска замечаний, перехода к ним и исправлений по явной команде пользователя.

### Хранение и передача
Текст и результаты обрабатываются в среде плагина Figma в течение сеанса. Плагин не отправляет их разработчику или на внешние серверы и не записывает текст документа, результаты и игнорируемые замечания в постоянное хранилище. Манифест запрещает доступ к внешней сети. Аналитика, рекламные трекеры и сторонние сервисы обработки не используются.

В Figma clientStorage сохраняются только настройки: язык интерфейса, выбранные правила, область проверки, фильтр видимости и свёрнутые категории. Отдельная регистрация не требуется.

### Передача и сроки хранения
Разработчик не получает содержимое документов через плагин. Запрошенные пользователем исправления становятся частью документа Figma и подчиняются настройкам хранения и доступа Figma. Данные сеанса не сохраняются плагином после его завершения; настройки могут оставаться в хранилище Figma.

Figma и GitHub самостоятельно обрабатывают данные согласно своим политикам: [Figma](https://www.figma.com/legal/privacy/) и [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### Поддержка и выбор пользователя
При добровольном обращении через GitHub Issues содержание сообщения и публичный профиль могут быть видны другим. Не публикуйте конфиденциальные документы, персональные данные и клиентские тексты. Используйте обезличенные примеры. Для прекращения обработки закройте плагин; область проверки можно ограничить в настройках.

Вопросы конфиденциальности и запросы о добровольно предоставленных данных направляйте разработчику через [GitHub Issues](https://github.com/siskovaa42-lang/text-cleaner-support/issues), не раскрывая чувствительные сведения публично.

Актуальная редакция политики публикуется на этой странице.
