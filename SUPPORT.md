# Support / Поддержка

Report bugs or suggest improvements via [GitHub Issues](https://github.com/siskovaa42-lang/text-cleaner-support/issues).

Include the plugin version, Figma environment (desktop or browser), OS, interface language, steps to reproduce, expected and actual behavior, and a minimal synthetic example.

**Issues are public.** Never share client files, confidential text, credentials, personal data or screenshots containing sensitive information. Use anonymized examples. For privacy questions, open a general inquiry without sensitive details; the maintainer can agree on an appropriate contact method if needed.

Сообщайте об ошибках и предложениях через [GitHub Issues](https://github.com/siskovaa42-lang/text-cleaner-support/issues). Укажите версию плагина, среду Figma, ОС, язык интерфейса, шаги воспроизведения, ожидаемый и фактический результат и минимальный вымышленный пример.

**Обращения публичны.** Не прикладывайте клиентские файлы, конфиденциальные тексты, пароли, персональные данные и чувствительные скриншоты. По вопросам конфиденциальности создайте обращение без чувствительных деталей; при необходимости согласуйте с разработчиком подходящий способ связи.
